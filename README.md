# Сайт учебного центра (Янаул, Республика Башкортостан)

Полноценный многостраничный сайт: 72 страницы, каталог программ с поиском и фильтрами, отдельные страницы направлений и программ, рабочие формы заявок с реальной отправкой (Telegram, e-mail, Битрикс24, любая CRM через webhook), админ-панель для правки программ, цен, FAQ и отзывов, SEO-разметка.

**Технологии:** React 19 + TypeScript (серверный рендеринг в готовые HTML-страницы), чистый CSS на переменных, лёгкий JavaScript без библиотек, сервер на Node.js без внешних зависимостей. Есть PHP-обработчик заявок для обычного хостинга.

> Сайт собирается в статические HTML-страницы: они открываются мгновенно, хорошо индексируются Яндексом и Google и могут работать на любом хостинге.

---

## 1. Быстрый старт (на своём компьютере)

Нужен Node.js 18.17 или новее (https://nodejs.org).

```bash
npm install          # установить зависимости (один раз)
cp .env.example .env # создать файл настроек и заполнить его (см. раздел 4)
npm run build        # собрать сайт в папку dist/
npm start            # запустить: http://localhost:3000
```

После сборки в консоли выводится список данных, которых ещё не хватает (название, юр. сведения, фото, цены и т.д.).

## 2. Черновой режим

Сейчас в `site.config.json` включено `"draftMode": true`. В этом режиме:

- на страницах видны жёлтые пометки «**Нужно заполнить**» — где и какие данные добавить;
- сайт закрыт от индексации поисковиками.

Когда данные заполнены — поставьте `"draftMode": false` и пересоберите сайт. Пометки исчезнут, пустые блоки (например, «Отзывы» без отзывов, кнопки мессенджеров без ссылок) скроются автоматически, а `robots.txt` откроет сайт для поисковиков.

## 3. Как менять информацию

### Через админ-панель (проще всего)
1. Задайте `ADMIN_PASSWORD` в `.env` и перезапустите сервер.
2. Откройте `https://ваш-сайт/admin` (логин `admin` или значение `ADMIN_USER`).
3. Вкладки: **Заявки**, **Программы**, **Направления**, **FAQ**, **Отзывы**, **Документы**, **Настройки**.
4. Нажмите «Сохранить и опубликовать» — сайт пересоберётся за секунду. Перед каждым сохранением создаётся резервная копия в `data/backups/`. Если в данных ошибка, изменения автоматически откатятся.

В админке можно загружать фото документов, отзывов и видео.

### Через файлы
| Что | Файл |
|---|---|
| Название, телефоны, адрес, мессенджеры, юр. сведения, лицензия, Метрика | `site.config.json` |
| Направления обучения (тексты, SEO-заголовки) | `content/categories.json` |
| Программы: срок, формат, **цена**, описание | `content/programs.json` |
| Вопросы и ответы | `content/faq.json` |
| Отзывы (только реальные) | `content/reviews.json` |
| Документы об обучении | `content/documents.json` |

После правки файлов выполните `npm run build`.

**Добавить программу** — скопируйте блок в `content/programs.json` и поменяйте поля. `slug` — адрес страницы латиницей (например `svarshchik`), `category` — адрес направления из `categories.json`. Пустые `hours`, `format`, `price` на сайте показываются как «уточняется» / «по запросу».

**Добавить отзыв** — пример записи:
```json
{ "type": "text", "author": "Иван Петров", "role": "Стропальщик", "text": "…", "image": "", "video": "", "date": "Октябрь 2026" }
```
Типы: `text`, `photo` (фото благодарственного письма — поле `image`), `video` (ссылка YouTube / Rutube / VK или mp4), `organization`.

### Фотографии
- Первый экран: положите файл `public/images/hero.jpg` (горизонтальное фото специалиста на производстве, от 1600 px по ширине).
- Направления: `public/images/categories/<адрес-направления>.jpg`, например `public/images/categories/ohrana-truda.jpg`.

При сборке фото автоматически сжимаются и конвертируются в WebP нескольких размеров. Пока фото нет, показываются фирменные иллюстрации. Используйте собственные фото или фото со стоков с подходящей лицензией.

### Цвета и шрифты
В начале `public/css/styles.css` — блок `:root`: `--accent` (оранжево-золотой), `--navy` (тёмно-синий), `--graphite` и др.

## 4. Приём заявок

Все формы реально отправляют данные. Если ни один канал не настроен, посетитель увидит сообщение с телефонами — сайт **не показывает ложное «Заявка отправлена»**. Каждая заявка дополнительно сохраняется в `data/leads.jsonl` и видна в админке на вкладке «Заявки».

Настройте хотя бы один канал в `.env`:

- **Telegram** (рекомендуется — заявки мгновенно приходят на телефон): создайте бота у @BotFather → `TELEGRAM_BOT_TOKEN`; добавьте бота в чат и узнайте его ID → `TELEGRAM_CHAT_ID` (можно несколько через запятую).
- **E-mail**: `SMTP_HOST`, `SMTP_USER`, `SMTP_PASS`, `MAIL_TO`. Для Яндекс Почты: `smtp.yandex.ru`, порт 465, пароль приложения.
- **Битрикс24**: создайте входящий вебхук с правами CRM → `BITRIX24_WEBHOOK_URL`. Заявка создаётся как лид с UTM-метками.
- **amoCRM и другие CRM**: через интегратор (Albato, ApiX-Drive, Make) — `CRM_WEBHOOK_URL`, заявка приходит POST-запросом в JSON.

Защита от спама: скрытое поле-ловушка и ограничение числа заявок с одного IP.

## 5. Размещение в интернете

### Вариант А — VPS с Node.js (рекомендуется: работает админ-панель)
Подойдёт любой VPS (Timeweb Cloud, Beget, REG.RU, Selectel), 1 ГБ RAM достаточно.
1. Установите Node.js 20+ и nginx, загрузите проект в `/var/www/uchebny-centr`.
2. `npm install && npm run build`, заполните `.env`.
3. Автозапуск: `deploy/uchebny-centr.service` (инструкция внутри). Пользователь сервиса должен иметь права на запись в `content/`, `dist/`, `data/`, `public/uploads/`.
4. nginx: пример в `deploy/nginx.conf`, SSL — `certbot --nginx`.

### Вариант Б — обычный PHP-хостинг
1. На своём компьютере: `npm install && npm run build`.
2. Загрузите в `public_html`: всё содержимое `dist/`, файл `php/.htaccess` и папку `php/api/`.
3. Заполните `api/config.php` (Telegram, e-mail, Битрикс24 или webhook).
4. Проверьте, что `api/data/` закрыта от просмотра (там лежит `.htaccess` с запретом).

Админ-панель в этом варианте недоступна — контент меняется в файлах с последующей сборкой и загрузкой `dist/`.

### После публикации
1. В `site.config.json` укажите `siteUrl` (ваш домен) и выключите `draftMode`, пересоберите.
2. Добавьте сайт в Яндекс Вебмастер и Google Search Console, укажите `https://ваш-домен.ru/sitemap.xml`.
3. Создайте счётчик Яндекс Метрики и впишите номер в `analytics.yandexMetrikaId` — цели `lead_sent`, `phone_click`, `messenger_click` отправляются автоматически.
4. Зарегистрируйте организацию в Яндекс Бизнесе / 2ГИС — это важно для запросов «… в Янауле».

## 6. Что нужно заполнить перед запуском

- [ ] Название учебного центра, логотип (`brand.logoImage`)
- [ ] Юридические сведения: наименование, ИНН, ОГРН, адрес (`legal`)
- [ ] Сведения о лицензии на образовательную деятельность — **только если она есть**; от этого зависит, какие документы можно обещать
- [ ] Проверить перечень программ: в каталог добавлены типовые программы по указанным направлениям — уберите лишние и добавьте недостающие
- [ ] Сроки, форматы и цены программ (или оставить «по запросу»)
- [ ] Ответы в FAQ (помечены как требующие проверки)
- [ ] Ссылки WhatsApp, Telegram, MAX; e-mail; режим работы; координаты для карты
- [ ] Фото: первый экран, направления, реальные образцы документов (с закрытыми персональными данными)
- [ ] Реальные отзывы
- [ ] Политика конфиденциальности и согласие — шаблоны по 152-ФЗ, их нужно проверить у юриста и указать оператора. Также оператор обычно обязан подать уведомление в Роскомнадзор об обработке персональных данных

На каждой странице: уникальные Title и Description (у направлений редактируются в `categories.json`), один H1, логичная иерархия заголовков, канонический адрес, Open Graph, alt у изображений. Schema.org: `EducationalOrganization` (главная, контакты, о центре), `Course` (программы), `ItemList` (направления), `FAQPage`, `BreadcrumbList`. Автоматически создаются `sitemap.xml` и `robots.txt`.

Под ключевые запросы заточены: главная («профессиональное обучение в Янауле / Башкортостане»), `/rabochie-professii/`, `/obuchenie/perepodgotovka/`, `/obuchenie/povyshenie-kvalifikacii/`, `/obuchenie/neftegazovaya-otrasl/`, `/obuchenie/elektrosnabzhenie-i-elektrobezopasnost/` (электромонтёры), `/obuchenie/specialnaya-tehnika/`, `/obuchenie/ohrana-truda/`.

## 8. Устройство проекта

```
site.config.json        общие настройки
content/                контент (JSON)
src/                    шаблоны страниц (React + TypeScript) и сборка
  components/           шапка, подвал, формы, блоки
  pages/                главная и внутренние страницы
  build.tsx             сборка в dist/: страницы, фото, sitemap, поиск
public/                 стили, скрипты, изображения
server/                 Node-сервер: страницы, /api/lead, админка
php/                    обработчик заявок и .htaccess для PHP-хостинга
deploy/                 примеры nginx и systemd
```

## 9. Концепция относительно сайта-референса

Структура attestat24.ru (каталог направлений, этапы обучения, FAQ, отзывы, форма) взята за основу по функциональности, но сайт сделан самостоятельно и решает его слабые места:

- **5 секунд до ответа**: на первом экране сразу видно направления, формат, документы и как узнать цену; у референса это рассыпано по странице.
- **Поиск и фильтры по программам** — у референса их нет.
- **Отдельная страница у каждой программы** с формой «Узнать стоимость» — больше точек входа из поиска и выше конверсия.
- **Контакты всегда под рукой**: липкая шапка с двумя телефонами, нижняя панель «Позвонить / Заявка» на смартфоне, мессенджеры.
- **Честность вместо обещаний**: никаких придуманных цифр, лицензий, отзывов и цен — для недостающих данных есть явные места.
- **Отдельный путь для работодателей** — страница корпоративного обучения с формой для юрлиц.
